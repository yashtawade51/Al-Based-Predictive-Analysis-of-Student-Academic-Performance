# EduPredict – AI-Based Predictive Analysis of Student Academic Performance

EduPredict is an institutional educational analytics platform with AI-driven student performance forecasting, early-warning risk detection, and role-based access for Students, Teachers, and Administrators.

## Core Capabilities
- **AI Predictive Performance Engine**: Calculates expected final percentage, forecasted grade, and pass probability from continuous academic telemetry (attendance %, internal exam marks, and submission regularity).
- **Early Warning System**: Color-coded risk indicators (**Low / Medium / High Risk**) proactively flagging students requiring faculty guidance or tutoring.
- **Role-Based Access Control**:
  - **Student Portal**: Attendance monitoring (with `<75%` eligibility warnings), multi-semester marksheet with PDF download, tuition fee tracking with authenticated receipt generation, weekly timetable grid, and academic calendar.
  - **Teacher Portal**: Daily attendance marking with bulk select, internal/mid-term grade entry, class-wise analytics, early-warning student alerts, and personalized faculty remarks.
  - **Admin Portal**: Institution-wide governance, user and faculty roster, bulk CSV validation, timetable manager with **automated double-booking clash detection**, academic calendar management, and fee collection summaries.
- **Gemini AI Academic Advisor**: "Ask AI" chat assistant providing study plans, subject intervention advice, and exam prep tips via `gemini-3.5-flash`.
- **Material 3 Design**: Supports edge-to-edge layout, responsive dynamic theming, and dark/light modes.
